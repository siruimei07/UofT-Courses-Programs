## 真实规模与布局取舍

完整原始记录见 [performance.json](../reports/performance.json) 与 [browser.json](../reports/browser.json)。单次本机观察，不是硬件无关保证：

| 工作 | 规模 | 耗时 |
| --- | --- | ---: |
| 全目录规则检查 | 2,491 门课程 | 254.45 ms |
| 全目录图投影 | 2,491 课程节点、2,565 总节点、6,218 条关系 | 14.57 ms |
| 最密学科图投影 | HIS 115 门课程、727 条全部类型关系 | 0.67 ms |
| 最密学科 ELK | 同上 | 554.83 ms |
| CS Major 推荐 | 58 个候选 | 21.93 ms |
| 浏览器实际 ELK 动态加载 + 排列 | HIS 115 门课程，默认关系筛选 | 769 ms |
| 开发服务首个有效图 / 手机列表 | 1512×982 / 390×844 | 999 / 296 ms |

选择 React Flow + 固定课程级别列、学科泳道；ELK 在用户请求时加载，仅用于同级排列，避免改变课程级别含义。全量图投影单测验证每个课程都被保留（包括独立节点）、无重复位置、隐藏引用计数、OR 标签。浏览器按需展示真实子图并逐步扩大，没有一次渲染 2,491 张卡片后再把它们缩成不可读全景。

初始主 JS 约 280 kB / gzip 88 kB，图模块约 186 kB / gzip 61 kB；ELK 约 1.43 MB / gzip 442 kB，只有点击优化排列时才加载。构建的 chunk 大小提示来自这一独立可选包，保留提示与测量记录。

## 数据与语义边界

2,041 条非空先修中，946 条完全结构化，1,095 条含未知条件。完整专业入学与完成条款保留 unknown；清晰分组可支持可解释推荐，不能宣称完成所有毕业要求。复杂学分分配、成绩作用域、placement、cohort/stream、共享限制、许可、年度动态 cutoff 不会因只识别出一个课程代码而被判为满足。

全量引用包括 1,186 个其他校区身份和 387 个当前 UTM 目录外身份，保留来源。先修引用图有 3 个 SCC：FSC307H5 自引用、FSC407H5 自引用、LIN104H5 ↔ LIN105H5。它们含备选和未知条款，不能直接视为强制环路或课程不可修读。

新增回归覆盖了真实条款中 OR 绕过学分/分数前缀的风险、UTMCIP 父级适用性、Group B 选修池分配、计划与并修区别、低于 50% 的失败成绩、互斥课程学分冲突、完整/不完整档案、跨校区身份、独立模拟与环路遍历。年度采集另测试批次隔离，防止中断刷新后把旧详情混入新快照；发布门禁对 Catalog、manifest 和质量报告进行关联校验。

尚未测试真实 GitHub Pages 线上 URL、Safari/Firefox 或屏幕阅读器全流程。没有实际开课、席位和注册数据；没有上传学生记录、远程分析、自动同步、定时任务或历史版本 UI。
